다음 카드에 알릴 것:
- 창은 [from + k·60s, +60s). 학습은 from을 분 경계로 내림, 점수는 [now−60s, now) 창 하나(Query StepSec 60, 계열별 창 평균 → HostAgg → TimeAgg). 값 없는 창은 0.
- 라벨: 창 [t, t+60s)가 [start−lead, end]와 겹치면 1(end 포함, 진행 중 장애 end = 구간 끝).
- runs_failed는 ListRuns(Status FAILED·TIMEOUT·KILLED·LOST, scheduled_at이 from−24h~to)에서 EndedAt이 창 안인 수.
- 모드 판정: 장애 < min_incidents 또는 양성 창 < 10이면 rule(노트 "규칙 기반 · 학습 사례 부족(장애 n건, 최소 m건)"), 아니면 Cfg.Model로 Fit. model: rule이면 늘 rule(노트 "규칙 기반(설정)"). llm이면 New에서 Build("llm")해 학습 없이 mode model, Score 에러면 rule로 대신 계산하고 노트 "규칙 기반으로 대신 계산 · llm 점수 실패". B9의 llm 모델은 Build(kind, nil, env)로 만들어지며 Fit은 train에서 부르지 않는다.
- 학습 전 노트 "규칙 기반 · 아직 학습 전". 첫 학습은 Run 시작 1분 뒤(백그라운드, 겹치지 않음).
- model.json: {"kind","lead_sec","report":FitReport,"model":{kind,features,mean,std,weights,bias,report}}. 종류가 설정과 다르면 무시하고 rule로 시작.
- risk.index: 호스트 "_eum", 점수마다 1개(ts = 계산 시각 ms), 값은 0~100 정수.
- Current()의 Score.Factors는 nil이 아니라 빈 배열. GET /risk는 아직 점수가 없으면 즉시 한 번 계산.
- POST /incidents → 201 + 장애 객체(id 포함), 400(start·title 없음, end<start). PATCH → 200 + 장애, 없는 id 404. 시각은 unix ms.
- POST /incidents/import 본문 CSV → {"imported":n,"errors":[줄별 메시지]}, 넣은 게 0이고 에러면 400. 제목이 빈 줄은 "장애".
- GET /export/risk-dataset: ts(ms),cpu_max,mem_max,hosts_hot,queue,p99,lag,log_errors,runs_failed,label. 기본 최근 7일, 최대 31일.
- POST /risk/train 응답 {"report":FitReport,"mode","note"}. 감사 actor는 "user:web(<원격 IP>)"(05 §7), action risk.train · incident.create · incident.update · incident.import.
