# contune (Con-A-Tune)

배치 스케줄러, 서버 관제, 업무 지표 수집을 한 제품으로 새로 만든 **경량 스케줄러·관제 통합 도구**입니다. 비싸고 거대한 상용 제품 없이, 운영에 실제로 쓰는 기능과 **데이터 주권**을 함께 갖는 것이 목표입니다.

핵심 아이디어: **스케줄러가 실행마다 실행 ID(`exec_id`)를 발급하고, 그 실행의 자원, 같은 시각의 서버 지표, 업무 지표를 같은 키와 같은 시간축으로 우리 DB에 쌓습니다.** 배치가 업무 처리에 영향을 주면 화면 하나에서 클릭 한 번으로 원인을 찾고, 같은 데이터를 SQL과 CSV로 꺼내 통계나 머신러닝에 씁니다.

## 결정 사항 (2026-10-27)

| 항목 | 결정 |
|---|---|
| 언어 | Go (단일 바이너리: `manager`, `agent`, `dev`, `burn`, `sql`) |
| 해커톤 | 하루, 2명. 코드는 당일 처음부터 작성(대회 규칙). 사전에는 설계 문서, 작업카드, AI 지시문만 준비 |
| 심사 | 서류: 창의성 30, 업무 도구 실용성 30, 구현 가능성 20, 기대 효과 20 |
| 산출물 | 새 스케줄러의 **개념 검증판**. 15:00까지 개념 6개(스케줄, 원격 실행, 한 통로 지표, 실행 ID 연결, 데이터 주권, 보안 최소선)를 최소 형태로 잇고 이후에는 넓히기만 함. 기존 도구 연결이나 단계적 이행 계획은 두지 않음 |
| 데이터 주권 | 공개 스키마, 분석용 뷰 `v_samples`, `contune sql`(읽기 전용), CSV 내보내기 |
| AI | 제품 기능이 아니라 개발 수단(사람 1명당 AI 세션 2개) |
| 업무 지표 | 초당 주문 건수, 응답시간을 시스템 지표와 같은 통로로. 검증판 수치는 시뮬레이터 |
| 시연 | Docker Compose: 매니저 1 + 에이전트 3, 수치는 시뮬레이터 수집기 |
