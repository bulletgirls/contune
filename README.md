# contune (Con-A-Tune)

Control-M(배치 스케줄링) + onTune(서버 관제) + APM(사내 업무 모니터링)을 하나로 묶은 **경량 통합 관제·배치 실행 도구**입니다.

핵심 아이디어: **잡 실행 ID(`exec_id`)로 배치 기동, 잡 프로세스 자원, 서버 지표, 업무 지표를 같은 키와 같은 시간축에 묶습니다.** 배치가 업무 처리에 영향을 주면 화면 하나에서 클릭 한 번으로 원인을 찾을 수 있습니다. 기존 Control-M 잡 명령 앞에 `contune exec --job <이름> --` 한 줄을 붙이면 연결되므로, 지금 쓰는 도구와 절차를 그대로 둔 채 도입할 수 있습니다.

## 결정 사항 (2026-10-27)

| 항목 | 결정 |
|---|---|
| 언어 | Go (단일 바이너리: `manager`, `agent`, `exec`, `dev`, `burn`) |
| 해커톤 | 하루, 2명. 코드는 당일 처음부터 작성(대회 규칙). 사전에는 설계 문서, 작업카드, AI 지시문만 준비 |
| 심사 | 서류: 창의성 30, 업무 도구 실용성 30, 구현 가능성 20, 기대 효과 20 |
| 1단계 범위 | 컷 1: 지표 통로, `contune exec` 래퍼, 타임머신. 컷 2: 매니저 실행과 플로우 스케줄 |
| AI | 제품 기능이 아니라 개발 수단(사람 1명당 AI 세션 2개) |
| 업무 지표 | APM이 보는 지표(초당 주문 건수, 응답시간)를 시스템 지표와 같은 통로로. 실제 수집 연계는 2~3단계 |
| 시연 | Docker Compose: 매니저 1 + 에이전트 3, 수치는 시뮬레이터 수집기 |
